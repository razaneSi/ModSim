About MarkovSim

MarkovSim is an interactive tool for modeling and simulating discrete-time Markov chains. Configure transition matrices, set initial distributions, and visualize probability evolution over time.

Features

  • Dynamic N×N transition matrix editor
  • Real-time probability evolution charts
  • Automatic steady-state computation
  • Built-in exercise presets (TP1 exercises)
  • Step-by-step distribution viewer

Backend

Powered by Flask + NumPy for computation and Matplotlib for graph generation.

TP1 – Modélisation et Simulation – Chaîne de Markov

Settings

Chart Resolution

Charts are rendered at 130 DPI by the Flask backend. High-resolution display is automatic.

Maximum Iterations

The simulation supports up to 200 iterations. Increase the slider range by editing the HTML.

Matrix Size

Use the +/− controls in System Configuration to resize the matrix (2–6 states supported).
